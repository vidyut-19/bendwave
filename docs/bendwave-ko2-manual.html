((7)) four signature transition playbooks LIVE PERFORMANCE MOVES · WORKS WITH K.O. II + STEMS
01 · looped echo-out transitionCLASSIC BLEND
1. Sync Deck B (U), pre-listen via /, click Co-Pilot PREP B.
2. Slide crossfader to center while sweeping Deck A FLT up (high-pass).
3. Hold Deck A 4 (1B roll) + G (Echo Out) for 4 beats → pull A VOL down → release into the echo tail as B's drop hits.
02 · 8-bar bass pull + 3/4 delayFRED / FOUR TET
1. On a stemmed track in a DROP, click rose BAS pill to drop sub-bass while highs, vocals, and drums float.
2. Set DLY fraction to 3/4 (dotted), FB ~0.65; punch DLY on one vocal phrase.
3. Watch HUD countdown (8 bars) → slam BAS back in on Beat 1.
03 · drums-only ∅ harmonic resetKEY CLASH ESCAPE
1. Need to jump across incompatible Camelot keys (e.g. 12B → 8A)?
2. Shift-click amber DRM pill on Deck A (solos drums only = null node ∅) & engage a 4B latched loop.
3. Harmonic context resets cleanly — fade in Deck B's intro, then cut A's drums on B's first kick.
04 · co-pilot phrase-locked swapFAST CURATION
1. Pick mode FLOW / LIFT / CHILL in CO-PILOT and click any Top-5 pick.
2. Track auto-loads & cues on the idle deck; check the 5-point card for KICK owner & [!] VOX CLASH.
3. Launch on HUD countdown (BUILD → DROP IN 8.0) so drops align bar-for-bar.
